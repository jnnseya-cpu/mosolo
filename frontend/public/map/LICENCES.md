# Fichiers de carte servis par MOSOLO

- `fonts/` : polices Noto Sans (SIL Open Font License 1.1), converties en glyphes MapLibre par le projet Protomaps (basemaps-assets).
- `sprites/` : icônes du style Protomaps « light » (licence BSD-3-Clause / CC0 selon les fichiers de basemaps-assets).
- Tuiles `/tiles/kinshasa.pmtiles` (non versionnées) : données © contributeurs OpenStreetMap, licence ODbL — l'attribution est affichée sur chaque carte. Fabrication : `tools/maps/construire-tuiles-kinshasa.sh`.
